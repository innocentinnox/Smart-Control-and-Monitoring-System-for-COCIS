\section{Building, Running and Demonstrating}
\label{app:build}
% ============================================================================

\subsection{Build and run the firmware}
\begin{lstlisting}[style=console]
. C:\Espressif\tools\Microsoft.v6.0.3.PowerShell_profile.ps1   # activate ESP-IDF v6.0.3
cd firmware
idf.py set-target esp32s3        # first time only
idf.py build
\end{lstlisting}
Then open \file{firmware/} in VS Code and run \textbf{Wokwi: Start Simulator} (it reads
\file{wokwi.toml}). Click the serial monitor and type \code{help}. To present a card, click the
ENTRY or EXIT reader, choose a card in its panel and press \textbf{Tap}. Key \code{e} presses the
break-glass button.

\subsection{Running the Wokwi link}
\label{app:wokwi-link}
Open \wokwilink{} and press play: wokwi.com builds the firmware from the project's source files
with its online ESP-IDF builder and starts the simulation. The project holds the same sources as
the repository, in one folder (\file{firmware/wokwi/web/}), because the online builder has no
components or menuconfig; the code builds unchanged on both ESP-IDF versions.

\subsection{Demonstration script}
The defaults are 07:00--22:00, Monday to Saturday, so run it during those hours.
\code{ENTRY} and \code{EXIT} are the two readers.

\begin{lstlisting}[style=console]
status                          # overview, both RFID readers OK
<ENTRY: Tap Blue>               # Alice enters             -> Welcome Alice, entry door opens
<ENTRY: Tap Blue>               # again                    -> DENIED ANTI_PASSBACK
<EXIT: Tap Blue>                # Alice leaves             -> Goodbye Alice, exit door opens
<ENTRY: Tap Key fob>            # unregistered card        -> DENIED UNKNOWN_CARD
<Room 1: LDR below 150 lux, click PIR>   # occupied + dark -> lamp 100 %, LCD "R1 100% P-"
<wait about 20 s>               # dims to 30 %, then off at 30 s
<LDR above 400 lux, click PIR>  # bright                   -> lamp stays off, LCD shows S
<ENTRY: Tap Green, Tap Yellow>  # Bob and Carol enter
login                           # then on a reader: Tap Red (admin card), then:
login 1234
schedule set 07:00 08:00 all    # a window that has already ended today -> SHUT
<EXIT: Tap Green>               # Bob refused: OUTSIDE_HOURS + ALERT AFTER_HOURS_EXIT
<EXIT: Tap Yellow>              # Carol (security) leaves  -> escort window opens for 60 s
<EXIT: Tap Green>               # Bob leaves               -> OK_ESCORT
node 2 offline                  # 15 s later: ALERT NODE_OFFLINE, LCD "R2 offline"
node 2 online
<press e>                       # break glass: both doors open, alarm, EMRG
emergency clear
schedule set 07:00 22:00 mon-sat
who
log tail 20
log verify                      # OK: hash chain intact
\end{lstlisting}
